# Aerospike SDK Mapper Java

Java Object Mapper for the [Aerospike Java SDK](https://github.com/aerospike/aerospike-client-java-sdk). 
Maps annotated or externally-configured Java POJOs to Aerospike records and back, providing CRUD, batch reads, 
query/scan support.

**Status:** Work in progress.

**SDK dependency:** Requires the `CLIENT-4861` branch of the Aerospike Java SDK (`com.aerospike:aerospike-client-sdk`), 
installed to the local Maven repository.
